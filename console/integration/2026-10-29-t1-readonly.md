## 本轮范围

- `agent/system_agent.py` 是临时 T1 Python 系统采集器，复用 `SystemProbe`，不是后续生产 Rust agent，也不是运动服务。
- 仅读取 `/proc`、CPU/SOC thermal zone 和指定 `aic3104` ALSA 枚举；1 Hz 发布。CPU 首次采样、读失败及缺失字段保持未知。
- 不打开 DXL、I²C、GPIO、音频流或 robotd IPC，不创建控制端点，不修改参数，不运行策略，不启用 systemd 服务。
- ZMQ TCP PUB/SUB 使用 CURVE：主机固定机器人公钥，机器人仅接受配对的主机公钥。robot_id、hostname、协议版本共同校验；错误来源、重复序号、乱序及已退役启动会话被拒绝。
- `boot_id` 为每次 agent 启动的会话 UUID，`os_boot_id` 为板端 Linux boot ID。`sample_time` 为板端 monotonic，仅用于同一会话排序；失联判断使用主机接收时间。未实现运动控制所需的跨机时钟协商，不可开放真实控制。
- 主机后端直接拒绝真实设备所有控制请求。真实数据使用 `source=robot`，录制保留该来源；关节、力矩、电压、Pin31、两颗 IMU 与运控均为未知/未接入。
- UI 不增加数据年龄项；3 秒没有有效系统帧标离线，实时指标清为未知。定格、回放仍明确标识。
