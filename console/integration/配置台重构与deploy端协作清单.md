日期：2026-11-03。对应 openchicken_console 的阶段卡片重构。本轮只修改监控端、进行本地模拟验证，不连接机器人，不修改 deploy 仓库或机器人服务。

## 监控端当前交付

- 保留双语网址、light/dark、机器人选择、URDF、Robot Status 和关节曲线。
- 顶部「连接设置」统一 SSH 指纹、当前页面凭据、遥测和共享路径；普通与管理员账户分别输入一次、同页复用，切换连接目标或刷新页面清除。

- N01/N02/N04/N05/N06「检查本阶段」仅采集对应项目；结果按机器人和阶段保存，恢复时核对地址、SSH 端口和账户。
- N03 保留 14 关节 ID、方向、Homing Offset 的期望值编辑、只读审计和差异表；跨阶段切换保留未保存的编辑。保存期望值只保存档案，不写舵机。N03 已取消独立人工记录卡片，机械核对/备注在关节表中选填，每次检查的读数与差异自动归档到 History。

- N04 IMU、电压和供电摘要来自当前实机遥测；断线/模拟不算有效实机读数。相机、录放音、离线推理没有假装成可执行成功按钮。
- 原始结果集中到「诊断记录」，可导出；机器采集和人工验收分开，采集完成不自动通过阶段。

### N03 现有入口与缺口

现有监控端默认调用机器人部署目录下的 `scripts/audit-servo-config.py`，并依赖同目录 `test-dxl-communication.py`。这些不等于部署包里的 `robotctl`。应由 deploy 明确提供受支持的版本/路径，或者提供原生等价读回接口；监控台再替换调用入口。不能假定每个新机二进制部署包都已经包含它们。

方向字段指 Drive Mode bit 0，不等同于 URDF 轴正方向。Homing Offset 使用 count。ID 与装配部位的真实对应、机械方向仍需现场核对。直接硬件写入及总线交接不在本轮 UI 修改范围内。

## 接口返回约定（待 deploy 确认）

监控台需要简短结构化结果，而不是解析面向人的整段终端输出。建议每项返回：

- `item`：稳定项目名称；`state`：unknown / missing / configured / running / failed / busy。
- `summary`：一句话结果；`observed_at`：读取时间。
- `values`：显示所需的关键事实，例如版本、服务状态、ID、方向、offset。
- `changed`、`backup_path`、`restart_required`：仅有修改时使用。
- `error_code` 与简短 `error`：失败原因；详细 stdout/stderr 单独归档供诊断。

状态查询只读；安装操作可重复执行，并在完成后查询实际结果。部署仍复用 deploy 仓库现有 list/status/apply/rollback，不把安装脚本散落到页面。

## 保留的必要约束

取消重复手工确认和多处重复配置；凭据按账户复用，当前任务防重复提交。保留目标身份、输入范围、操作结果/写后回读、总线唯一持有者以及原生最终执行层的使能/断矩/命令失效处理。网络中断后先查询实际状态，不自动重放安装或运动请求。

电池极性属于硬件接线核对，监控端不能通过软件证明“不接反”；不能用页面的供电状态替代接线检查。

## 集中联调顺序

1. 在隔离本地实例确认两种语言、主题、阶段切换和表格；所有 SSH 请求使用替身。
2. 待 deploy 入口确认后，现场连接目标机器人，核对 SSH 指纹及账户。
3. N01/N02 只读检查 → N03 无力矩且独占总线的参数回读 → N04 外设功能 → N05 服务/configd/蓝牙及遥测 → N06 隔离推理。
4. N07/N08/N09 在运行控制台逐项进行实机动作验证，按原有最终输出约束执行。
5. N10 核对结束状态、回滚与恢复，归档结果。本地测试通过不替代上述实机验收。


## 舵机参数展示与运行中读取（2026-11-04）

监控端已将 N03 审计的实测寄存器接入 Servo parameters：PID、PWM slope/limit、Homing Offset 和 Drive Mode，按档案目标、关节名称和实际 ID 匹配，明确标注采集时间及非实时来源。期望值不作为测量值。力矩和硬件错误仅展示当前反馈/回放数据，不使用旧审计值冒充当前状态。

现有 runtime 桥接将上述参数设为 null；检查当前原生 IPC 接口后，尚未找到可供监控调用的运行中寄存器只读查询。deploy 端需由已有总线持有者 robotd 提供参数实测快照（每关节 ID、读取时间、读取成功字段以及 PID、PWM、Homing Offset、Drive Mode），再由 agent 透传。不能以 robotd.toml 中期望配置冒充读取值，也不从监控端并发打开正在使用的舵机总线。

本轮未修改或部署 robotd/agent，没有执行实机寄存器读取。已有 N03 入口仍遵守原有独占总线回读条件；“加载回读记录”只读取本地档案，不执行 SSH。
